# IsRight 入口（本機副本）

網站：https://huangisright.github.io/　原始碼：huangisright/huangisright.github.io

## 怎麼更新

1. 改 `data.json`（分類的 items、未完成的 drafts、repos）。
2. 在這個資料夾跑 `python3 build.py`，會重產 `index.html` 與 `c/*.html`。
3. 推上 GitHub（或請 Claude 推）。

## 未完成 → 完成

確認某一頁完成後：把 `draft/<slug>.html` 搬到該分類的資料夾，再把它從 `drafts` 移到該分類的 `items`。
