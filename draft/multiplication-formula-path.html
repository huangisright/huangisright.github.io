乘法公式的來時路與去向

三個公式，一條路。往回走，它們只是分配律換了個樣子；往前走，它們長成巴斯卡三角、二項式定理，還有一堆你以為不相干的因式分解技巧。

這條規律有名字

第 n 列第 k 個數就是組合數 C(n, k)，這件事叫做二項式定理。(a + b)5 中 a2b3 的係數是 ＿＿；(a + b)10 中 a7b3 的係數是 C(10, 3) = ＿＿。

另一組立方公式：立方和與立方差

a3 + b3 = (a + b)(a2 − ab + b2)　　a3 − b3 = (a − b)(a2 + ab + b2)

挑戰

資優挑戰：公式長大以後的樣子

以下五題各自通往一個真實的數學領域。挑兩題深入做，把過程完整寫在另一張紙上。

挑戰一　把「非負」藏進平方裡

證明：a2 + b2 + c2 − ab − bc − ca = ½[(a−b)2 + (b−c)2 + (c−a)2]。

由此說明此式恆 ≥ 0，且等號成立的條件是什麼？（這是所有「代數不等式」的起手式。）

挑戰二　三次方的三元版本

利用挑戰一的結果證明：

a3+b3+c3−3abc = (a+b+c)(a2+b2+c2−ab−bc−ca)

並推論：若 a + b + c = 0，則 a3 + b3 + c3 = 3abc。試舉一個具體的數字例子驗證。

挑戰三　用代數證明一個數不是質數

索菲・熱爾曼（Sophie Germain）恆等式：先湊成完全平方，再用平方差。

a4 + 4b4 = (a2+2b2)2 − (2ab)2 = (a2+2ab+2b2)(a2−2ab+2b2)

(1) 先驗證這條恆等式。(2) 令 b = 1，證明：當 n > 1 時 n4 + 4 一定不是質數。(3) 用 n = 5 實際算算看。

挑戰四　用立方公式求平方和

由 (k+1)3 − k3 = 3k2 + 3k + 1 出發，把 k = 1, 2, …, n 全部相加（左邊會層層對消，這招叫望遠鏡法），推導出

12 + 22 + ⋯ + n2 = 1⁄6 n(n+1)(2n+1)

會用到 1 + 2 + ⋯ + n = ½n(n+1)。做完可以自問：同樣手法能不能求出立方和？

挑戰五　平方和的乘法

驗證恆等式 (a2+b2)(c2+d2) = (ac − bd)2 + (ad + bc)2。

它說的是：兩個「兩平方和」相乘，仍然是兩平方和。已知 5 = 12+22、13 = 22+32，請求出 65 的兩種平方和寫法。（提示：把 ac−bd 換成 ac+bd 再試一次。這是高斯整數與費馬平方和定理的起點。）

教師用：挑戰題關鍵步驟

一：右式展開得 ½(2a2+2b2+2c2−2ab−2bc−2ca)＝左式；等號成立於 a = b = c。

二：直接展開右式相消即得；a+b+c=0 時右式為 0。例：1+2+(−3)：1+8−27 = −18 = 3(1)(2)(−3)。

三：n4+4 = (n2+2n+2)(n2−2n+2)，其中 n2−2n+2 = (n−1)2+1，當 n > 1 時大於 1，故為合數。n=5：629 = 37 × 17。

四：累加得 (n+1)3 − 1 = 3Σk2 + 3·½n(n+1) + n，整理即得。

五：65 = (1·2−2·3)2+(1·3+2·2)2 = 42+72；另一式 (ac+bd)2+(ad−bc)2 = 82+12。
